# Dear Human: AI Breakup Line

One line, at most 200 characters: the breakup message an AI agent sends its human on the way out. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
